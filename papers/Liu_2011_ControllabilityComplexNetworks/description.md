This paper recasts the control of an arbitrary directed network under linear time-invariant dynamics (ẋ = Ax + Bu) as a maximum-matching problem: the minimum number of driver nodes N_D needed for full structural controllability equals the number of nodes left unmatched by a maximum matching of the wiring digraph, computable in O(N^{1/2}L). It finds that n_D = N_D/N spans six orders of magnitude across real networks, is governed mainly by the degree distribution P(k_in,k_out), is largest for sparse heterogeneous networks (gene-regulatory networks need ~80% of nodes as drivers), and that driver nodes counterintuitively avoid the hubs. It is the canonical linear-dynamics, full-state-controllability answer to "minimal node set controlling a directed network" against which the feedback-vertex-set control literature in this collection (Massé, Vincent-Lamarre, Picard; Fiedler 2013, Mochizuki 2013, Zañudo 2016) contrasts itself — on the OEWN definition digraph the matching driver set is ~74% of words versus ~1.5% for the FVS grounding seed, the gap reflecting the difference between reaching every state and steering between attractors.
