This paper proves that for ODE regulatory networks on a directed graph (under a uniform decay/dissipativity condition) the graph-theoretic feedback vertex set coincides with the dynamical notions of informative nodes (Mochizuki-Saito) and determining nodes (Foias-Temam), so observing only a feedback vertex set pins down the entire network's long-time dynamics for every admissible nonlinearity and overriding it via open-loop control forces the rest of the network onto any prescribed trajectory. It establishes the determining-nodes theorem and the global-attractor reconstruction theorem, demonstrates them on Lorenz, Frobenius and three biological networks (ascidian gene network reduced to a single feedback vertex FoxD-a/b; EGF signaling with 36 minimal 5-vertex feedback sets; a 21-variable mammalian circadian model where clamping a 7-vertex feedback set controls the whole system), and discusses minimal-FVS search (NP-complete) plus reductions to the cyclicity set. It is foundational for this project because a definition digraph's lexical grounding set / MinSet is exactly a feedback vertex set, so this is the canonical result that overriding the grounding set (plus source nodes) determines the rest of the lexicon regardless of how definitions compose.
