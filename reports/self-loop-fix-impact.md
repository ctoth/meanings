Lexicon: `oewn:2024` — 160,010 nodes, 677,823 edges, **3,413 self-loops** (words that appear in their own gloss).

Generated by `scripts/self_loop_fix_impact.py`. "With self-loops" = current (post-fix) `compute_kernel`; "pre-fix baseline" = same pipeline on a self-loop-free copy of the graph (reproduces the old behaviour).

Notes:
- All self-loop nodes belong in the Kernel by definition (a 1-node cycle is a forced feedback-vertex-set member); pre-fix they were silently dropped. The self-loop fix's *only* effect is the Kernel-size increase shown above (the new self-loop nodes plus the acyclic upstream that used to be stripped with them).
- If `residual cyclic SCC` is non-zero for a method, `analyze_kernel` skips the layer map (`compute_layer_map`), so the layer histogram comes out empty for that method. `bounded-scc` (8-pass cap) already left a residual cycle on the *pre-fix* Kernel — that is a property of the bounded heuristic on a large Kernel, not of the self-loop fix. The fix does push `exact-cutting` (single-pass cutter) from 1 to several residual SCCs, because the larger Kernel has more big SCCs the one-shot pass cannot fully crack. `exact-small-greedy` (loops to completion) gives `residual = 0` and a full layer map both before and after.
- The committed `reports/oewn-paper-wordnet-kernel-*.{md,json}` predate both this fix and the MinSet-solver refactor; regenerate via the CLI.
- Example self-loop words: `aah::v`, `aba::n`, `abaca::n`, `abelia::n`, `abraham::n`, `absinthe::n`, `abudefduf::n`, `abyssinia::n`, `acacia::n`, `acanthoscelides::n`, `acanthus::n`, `acaridae::n`.
