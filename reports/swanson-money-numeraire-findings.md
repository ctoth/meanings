# "Meaning has no gold standard": the symbol-grounding problem as the numéraire problem

**Date:** 2026-05-12
**Type:** Swanson-link findings report (literature-based discovery)
**Status:** complete (first pass)
**Prompt:** `reports/research-swanson-1-money-numeraire.md`

## What this report is

The research prompt hypothesised that the dictionary-graph / symbol-grounding literature (Massé 2008, Picard 2013, Vincent-Lamarre 2014, Harnad 1990) and the monetary-economics literature on the *numéraire* and *commodity standards* (Walras, Sraffa, Patinkin, general-equilibrium theory) are describing the *same formal object* — a relational value system with no intrinsic content, where "grounding" is an arbitrary choice of anchor — and do not cite each other. This report (1) maps the correspondences, (2) reports the citation-disjointness evidence and the closest near-misses, (3) ranks the tools economics could lend back with feasibility notes, (4) states the falsifiers, and (5) names the paper that should exist.

A reading caveat up front: the repo "paper" files (`reports/paper-*.md`) are paper-reader summaries with verbatim abstracts and page-cited claim lists, not the page images themselves; I relied on those summaries plus their verbatim quotes. On the economics side I was able to read secondary treatments of Sraffa (Glasgow CS report; Ian Wright's "The real meaning of Sraffa's standard commodity"; Broome's "Sraffa's Standard Commodity" — abstract/metadata only, the PDFs would not text-extract) and Wikipedia/quantecon on Perron–Frobenius applications, plus general-equilibrium notes (Levin, Stanford; Toda's ME notes; Arrow–Debreu / SMD on Wikipedia). I could **not** obtain a clean text of Sraffa's *Production of Commodities by Means of Commodities* (1960) itself — the wegivethe99percents PDF mirror refused connection — nor a clean text of Patinkin's *Money, Interest, and Prices*. Quotes attributed to Sraffa below are quoted *via* the secondary sources that quote him; this is flagged inline. That is the main thing I could not verify directly.

## 1. The correspondence table

Notation: D = dictionary; K = Kernel; C = Core (largest source SCC of K); S = Satellites (smaller source SCCs of K); MinSet = a minimum feedback vertex set restricted to the definitional graph (Vincent-Lamarre's term; Picard's "MGS"; Massé's "minimum grounding set"). On the economics side: a commodity-production system à la Sraffa is a non-negative input matrix A; "basic" commodities are those used directly or indirectly in producing everything; "non-basic" the rest; the **standard commodity** is the composite commodity built from the (left) Perron–Frobenius eigenvector of the basics block; the **numéraire** is whatever bundle has its price fixed to 1.

| Dictionary-kernel concept | Monetary-economics concept | Shared formal object (if any) | Honest assessment of the fit |
|---|---|---|---|
| A word is defined only in terms of other words; "meaning all the way down" is impossible (Massé abstract: *"Meaning cannot be based on dictionary definitions all the way down: at some point the circularity of definitions must be broken"*). | A commodity's price/value is defined only in terms of other commodities' prices (Sraffa's title literally: *Production of Commodities by Means of Commodities*); in pure GE there is no absolute price level, only ratios. | A homogeneous relational system: every element's value/meaning is a function of the other elements' values/meanings, with no exogenous unit. | Tight. Both are "no bottom" systems. The slogan "meaning has no gold standard" is, structurally, the GE fact that the price system is homogeneous of degree zero — *no absolute units exist, only relative ones*. |
| **Grounding set** / **MinSet**: a set of words that, if known from outside, lets all the rest be reached by definition. Equivalently a set that hits every directed cycle (Massé's core theorem: *"U is a grounding set of G ⟺ U ∩ C ≠ ∅ for every directed cycle C ⊆ G"*). | **Numéraire / commodity standard** (gold standard): an element designated as exogenously anchored ("=1") so the rest of the system can be priced relative to it. | A *normalisation choice* on a homogeneous system. In GE: pick `p_k = 1`. In dictionaries: pick a seed `U` to ground exogenously. | Strong but not perfect. Picking a numéraire `p_k=1` is a *single*-element normalisation that always works because the system is homogeneous of degree 1; a grounding set must be *large enough to hit every cycle* — it is an FVS, not a single coordinate. So the right economics analogue of "MinSet" is not "the numéraire good" but "the *smallest commodity basket whose prices, if posted exogenously, determine all the rest*" — which in a fully connected market is just one good, but in a *sparse* production network (basics + several disconnected non-basic subsystems) is one anchor per source component. See the Core/Satellite mapping below; this is exactly where the analogy stops being a pun. |
| There are **many MinSets, none privileged** (Vincent-Lamarre abstract: *"every dictionary has a huge number of MinSets"*; Picard: *"many overlapping Minimal Grounding Sets"*). | **Any commodity can serve as the numéraire** — the classic Walrasian observation. Levin (Stanford GE notes) and standard texts: equilibrium is unaffected by which good you set to 1; demand is homogeneous of degree zero in prices. | The set of valid normalisations is a continuum / a large combinatorial family; the *equilibrium real allocation* is invariant to the choice. | Tight, and this is the load-bearing match. Both literatures independently arrived at "the anchor is arbitrary; the structure is what's real." |

The dictionary literature has **no canonical MinSet** and explicitly says so. Sraffa's whole construction is "given that the numéraire is arbitrary, here is the canonical one, defined spectrally." That is a ready-made algorithm waiting to be ported. (See §3, tool 2.) |
| Going **off the gold standard** ≈ discovering the graph has **no Kernel that bottoms out** — meaning floats on pure relation, stabilised only by the cyclic Core being self-consistent. | Nixon shock 1971 / fiat money: the unit of account is defined by *nothing but* its role in the system; value is a fixed point of expectations, not a redemption claim. MMT vs Bitcoin-maximalism = "the system needs an external anchor" vs "it doesn't." | A fixed-point / self-consistency property: the cyclic Core is consistent (a non-vicious circle) the way a GE price vector is a fixed point of the excess-demand map, or a fiat price level is a fixed point of beliefs. | Good as rhetoric, suggestive as math. The real content is: *why is a circular definition not vicious?* The GE answer ("a fixed point exists by Brouwer/Kakutani") is a genuine candidate model for "why the Core is self-consistent rather than an infinite regress." Harnad's point survives intact: existence of a self-consistent fixed point is not the same as the symbols *meaning* anything — exactly as a self-consistent fiat price level does not make money "intrinsically valuable." The Harnad / distributionalist split *is* the MMT / Bitcoin-maximalist split, structurally. |
| **Core** (largest source SCC of the Kernel; *"Core words can define one another but not the rest of the dictionary"* — Picard) vs **Satellites** (the smaller source SCCs) vs **Rest** (~88–92%, the acyclic outer shell). | **Basic commodities** (used directly or indirectly in producing everything — they form the indecomposable / strongly-connected block of A) vs **non-basic commodities** (used in producing at least one thing not at all — they hang off the basics) vs the rest of the economy. | An SCC / source-component decomposition of a sparse digraph: one big strongly-connected "engine" + smaller appendages + an acyclic periphery. | This is the strongest *structural* match and the place the prompt's worry ("maybe money's structure is a complete graph, not a sparse digraph") is answered: **Sraffa's basics/non-basics distinction is literally an SCC decomposition of the production network.** Basics ≈ Core, non-basics ≈ Satellites/Rest. The Perron–Frobenius eigenvector is only defined on the *basics* block precisely because that block is irreducible — exactly the condition that the Core is strongly connected. So the two literatures have independently discovered: (i) the relevant object is a sparse digraph; (ii) it has an irreducible core; (iii) the "anchor" must live partly in that core. |

Both are "how many definitional/productive steps from the engine."|

That loose analogue is real and historically interesting but it is not a measured variable the way AoA is. |

The repo already has a diachronic-resources paper (`Ghizzota_2025`) and a loop-ecology line (`Levary_2012`). The monetary-economics dynamics (impulse responses, regime change) are a *target* for the dictionary literature, not a counterexample. The honest statement: the analogy as currently *exploited* is between static comparative-statics on both sides; the dynamic side is open on the lexical side. |
| **Cycles are not garbage** — short definitional loops are semantically coherent (`Levary_2012`; repo synthesis note "saves the loops from being treated as trash"). | A non-vicious circular price system — `p = (1+r)Ap + wl` is a *consistent* circular dependency, not a regress. | A self-consistent system of simultaneous equations / a fixed point. | Match. Both fields had to learn the same lesson: circularity ≠ pathology. Sraffa's whole point against the labour theory of value was that you can *solve* the circle; Massé/Levary's point is that you can *seed* it (FVS) and that the loops themselves carry structure. |
| **Harnad's residual**: even a perfectly closed, fixed-pointed definitional system is not *meaning* — symbols stay "parasitic" without external grounding (Harnad: *"How can the meanings of the meaningless symbols ... be grounded in anything but other meaningless symbols?"*; *"analogous to trying to learn Chinese from a Chinese/Chinese dictionary alone"*). | **Fiat money's residual**: a self-consistent price level does not make the token intrinsically valuable; the "value" is wholly conventional/relational (this is the standard chartalist/Wittgensteinian reading — the Glasgow CS report explicitly links Sraffa's value-relativism to Wittgenstein's "meaning is use"). | — (this is the *negative* claim both fields make about the closed system). | Tight, and it is the philosophical spine of the whole link: **Harnad : distributional semantics :: hard-money/Austrian : MMT/chartalism.** "You need an exogenous anchor" vs "you don't, the relational system is self-sufficient." The dictionary-graph papers sit *between* (Vincent-Lamarre treats MinSets as *candidates* for grounding, not as self-explaining atoms — the careful middle position). |

### Where the analogy breaks (collected)

1. **Single-coordinate normalisation vs feedback vertex set.** A numéraire is one price set to 1; it always works because GE prices are a ray. A MinSet must hit *every* cycle. The two coincide only when the relational graph has a single SCC and no disconnected pieces — i.e. when the economy is "all basics." The fix that *makes* the analogy precise is to map MinSet not onto "the numéraire good" but onto "the minimal exogenously-posted price basket sufficient to determine all the rest in a *disconnected* production network" — and to note that Sraffa's basics/non-basics split is exactly what creates that disconnection.
2. **No psycholinguistic exogenous signal in the economy.** AoA / concreteness have no monetary analogue (beyond loose historical "which commodities served as money").
3. **Static vs dynamic.** Exploited analogy is comparative-statics on both sides; monetary dynamics (velocity, policy, regime change) is an open target for the lexical side, not a disanalogy.
4. **Sign / non-negativity.** Production matrices are non-negative (you can't make a thing by un-using inputs); definitional graphs are just digraphs with no weights. Perron–Frobenius needs the non-negativity. So porting Sraffa's *spectral* construction to dictionaries requires first putting a non-negative weight on definitional edges (e.g. frequency-of-use of word u in defining v, or 1/out-degree). This is a concrete prerequisite, not a blocker. (See §3, tool 2, feasibility.)

## 2. Citation disjointness — evidence and near-misses

**Claim: the two literatures do not cite each other.** Supported, with the usual caveat that absence of evidence from web search is not proof.

**Direction A — does the symbol-grounding / lexical-graph literature cite Walras, Sraffa, Patinkin, Fisher, Hahn, or monetary-economics work on the numéraire?**
- Massé 2008's reference list (per the repo claim file, pp. 8–9) is Harnad, Tarjan, Karp, Steyvers & Tenenbaum, Fellbaum, Procter — graph theory + psycholinguistics + lexicography. No economics.
- Vincent-Lamarre 2014's references (per repo claim file, pp. 32–37): Blondin Massé, Picard, Steyvers & Tenenbaum, Harnad, Van Rensbergen/Storms/De Deyne, Kuperman, Brysbaert, SUBTLEX. No economics.
- Picard 2013: Blondin-Massé, Harnad, Lapointe (FVS enumeration), Levary, Procter, Wilson (MRC). No economics.
- Harnad 1990: Fodor & Pylyshyn, Searle, Newell, Gibson. No economics.
- The 2025 follow-up paper *"Approaching the Source of Symbol Grounding with Confluent Reductions of AMR Directed Graphs"* (arXiv 2508.11068): I fetched it via WebFetch and asked specifically — it **does not** mention economics, money, numéraire, Sraffa, Walras, Patinkin, or general equilibrium; its vocabulary is purely graph-rewriting ("confluence," "reduction," "feedback vertex set").
- Targeted search `symbol grounding problem dictionary graph "feedback vertex set" cite economics OR money OR numeraire OR Walras OR Sraffa` returned only the grounding literature and, *separately*, a Walras Wikipedia page — the search engine itself volunteered "the symbol grounding / feedback vertex set problem [is not directly connected] with economic concepts ... these may be separate topics."

**Direction B — does economics on numéraire choice / commodity standards cite Harnad, Massé, Vincent-Lamarre, or the dictionary-graph literature?**
- Searches `economics "numeraire" OR "commodity standard" paper citing "symbol grounding" OR "feedback vertex set" lexicon dictionary semantics` and `Harnad "symbol grounding" OR Vincent-Lamarre "latent structure of dictionaries" citing OR cited "general equilibrium" OR Sraffa OR Patinkin` returned: the Sraffa secondary literature on one side, the lexicon-graph literature on the other, **no overlap**. The closest the engine could offer was "It's possible such a connection exists in a specialized paper ... not indexed."
- Sraffa-and-Wittgenstein is a known scholarly thread (Sraffa actually influenced Wittgenstein — the "Naples gesture" anecdote; the Glasgow CS report and Ajit Sinha's work both develop "value of a commodity occupies the same space as meaning of a word"). But this thread connects Sraffa to *philosophy of language broadly*, not to Harnad's symbol-grounding problem or to the FVS/dictionary-graph formalism. It is a near-miss in *theme*, not a citation bridge.

**Closest near-misses (ranked by how close they come to being the bridge):**

1. **The Sraffa–Wittgenstein literature** (e.g. the Glasgow "Significance of the Standard Commodity" report; Ajit Sinha, *A Revolution in Economic Theory: The Economics of Piero Sraffa*, 2016). Verbatim from the Glasgow report's framing as relayed: *"For Sraffa, the value of a commodity in economics occupies the same space as meaning of a word in language"* and *"The value of a commodity is well defined for a given basic good system but value of the same commodity in two different basic good systems cannot be compared, as there exists no grounds for measuring them in two systems."* That second sentence is, almost word-for-word, Vincent-Lamarre's "every dictionary has a huge number of MinSets, none privileged" / "there is no canonical grounding set" — but neither side cites the other. This is the single closest near-miss: same claim, two literatures, zero cross-reference.
2. **"New monetary economics" (Black, Fama, Hall, Greenfield–Yeager, 1980s)** on *separating the unit of account from the medium of exchange* — i.e. the unit of account is a pure relational role with no commodity behind it. This is the economics statement most isomorphic to "meaning is purely distributional." Cited only inside monetary economics.
3. **Sonnenschein–Mantel–Debreu** (anything-goes for aggregate excess demand subject only to continuity, homogeneity-of-degree-zero, Walras's law): the economics result that says "the relational structure is *almost unconstrained* — only the homogeneity (= numéraire-arbitrariness) is forced." The lexical analogue would be "dictionary graphs can have almost any structure subject only to ...?" — nobody has asked. Cited only in GE theory.
4. **Distributional-semantics meta-literature** using the phrase "representational currency" (Boleda & co.: *"the fundamentally different 'representational currency' underlying these approaches — models of the world versus linguistic co-occurrence"*). This is a *dead metaphor* of exactly the right shape ("currency" = unit of semantic account) used in passing by linguists who do not develop it. A genuine near-miss in vocabulary; no economics cited.
5. **Quine's inscrutability of reference / indeterminacy of translation** ("there is no fact of the matter as to which meaning a foreign sentence has"). This is the *philosophical* statement of "meaning has no gold standard" and it predates the dictionary-graph formalism. Harnad's "Chinese/Chinese dictionary-go-round" is downstream of it. Quine never put it in economic terms; economists never cite Quine in numéraire discussions. The bridge would route through Quine, but doesn't.

Conclusion: genuinely disjoint citation graphs. The thematic near-misses (Sraffa–Wittgenstein; "representational currency"; SMD; new monetary economics) make the link *more* credible as a real Swanson link, not less — independent fields keep stating the same proposition in their own dialects.

## 3. What economics could lend back — ranked transferable tools with feasibility notes

**Tool 1 (highest value): General-equilibrium existence as the model for "why the cyclic Core is self-consistent, not vicious."**
- *The transfer.* The dictionary literature treats the Core/cycles as a fact to be *seeded around* (FVS). It has no positive theory of *why a circular definitional system is coherent*. GE has exactly this: prices are a fixed point of the excess-demand correspondence; existence follows from Brouwer/Kakutani given continuity + homogeneity-of-degree-zero + Walras's law. Reframe: a "consistent assignment of meanings to Core words" = a fixed point of a meaning-update map on the Core SCC; the cycle is non-vicious *iff* such a fixed point exists; multiplicity of fixed points = multiplicity of consistent semantic interpretations (which dovetails with Quine indeterminacy and with multiple MinSets).
- *Feasibility.* High as a *framing*, medium as *math*. Needs a concrete "meaning-update map" — e.g. each word's embedding = some pooling of its definers' embeddings, iterate to a fixed point (this is essentially what node2vec-on-definitions / dictionary-derived embeddings already do; it has just never been analysed as a GE-style fixed point). Risk: the relevant fixed-point theorem might be Banach (contraction) rather than Brouwer, which would be *less* interesting (unique, boring). Worth checking whether the definitional-pooling map is a contraction on the Core; if it is, the "multiple MinSets" multiplicity lives only in the *grounding* (boundary conditions), not the interior — itself a publishable observation.

**Tool 2: Sraffa's standard commodity as an algorithm for picking a canonical MinSet (or canonical seed weighting).**
- *The transfer.* Sraffa: the numéraire is arbitrary, *but* the (left) Perron–Frobenius eigenvector of the basics matrix is a distinguished bundle (it makes the wage–profit frontier linear, `w = 1 − r/R`, invariant to distribution). Port: put a non-negative weight `w(u,v)` on the definitional edge "u is used in defining v" (candidates: count of occurrences; 1/out-degree of u; tf-idf-style salience). The Core is the irreducible block (it's a single source SCC — Picard/V-L confirm it usually is). Compute the left PF eigenvector of the weighted Core adjacency matrix. The high-eigenvector-centrality words are the *canonical* grounding priorities; "round" this to an actual FVS (e.g. greedily take highest-centrality vertices until acyclic) to get a *canonical MinSet*. This directly answers Vincent-Lamarre's open question (*"Can weighted MinSets be defined to optimize not only size but semantic primitiveness?"*) and the synthesis note's wish for "a weighted objective ... not just minimum size."
- *Feasibility.* High. The repo *already* computes Kernels/Cores/MinSets on OEWN (the `oewn-*-kernel-*` reports). Adding a weighted-adjacency PF-eigenvector step is a few lines of `numpy`/`scipy.sparse.linalg.eigs`. Prerequisite: choose the edge weight (a defensible default: 1, i.e. unweighted PF / plain eigenvector centrality of the Core; then sensitivity-test against frequency-weighting). Caveat: this gives a *canonical* MinSet only relative to the chosen weighting — which is honest, and exactly parallel to Sraffa's standard commodity being canonical *relative to the choice "invariant to distribution."* The Swanson-paper move is: "there is no canonical MinSet" (current lexical lit) ⊕ "but here is the spectrally canonical one, à la Sraffa" — and then test whether the spectrally-canonical MinSet is also the psycholinguistically-privileged one (AoA/frequency). If yes: strong result. If no: still a result (the canonical-by-structure ≠ canonical-by-cognition, which is itself Harnad-flavoured).

**Tool 3: Seigniorage / cost-of-maintaining-the-anchor → "which grounding vocabulary is cheapest."**
- *The transfer.* Monetary economics asks which standard is *cheapest to maintain* (gold has mining/storage costs ≈ "the resource cost of the gold standard," Friedman; fiat has near-zero issuance cost ⇒ seigniorage). Map onto: which MinSet minimises *total definitional cost* — e.g. Σ over all words of (definitional distance to the seed) × (length of definition), or the total length of definitions you'd need to write to reach the whole dictionary from this seed. A "cheap" grounding vocabulary is one from which the rest of the dictionary unfolds in few short steps; an "expensive" one needs long chains. This converts "pick a MinSet" from a pure size-minimisation into a *cost*-minimisation with a clear economic interpretation, and it predicts the *fiat outcome*: the cheapest anchor might be tiny and "intrinsically worthless" (a few abstract function-ish words) — i.e. the lexical analogue of going off gold.
- *Feasibility.* Medium-high. All the ingredients (definitional distance hierarchies, definition lengths) are computable from the OEWN graph; the optimisation is an ILP variant of the FVS ILP the literature already solves (Vincent-Lamarre used CPLEX). Caveat: defining "cognitive cost" of a definition is squishy; length is a crude proxy. But "total definitional length to span D" is a perfectly clean, fully computable objective even if you don't believe it's *the* cost function.

**Tool 4: Monetary history as a natural experiment in swapping/removing the anchor.**
- *The transfer.* History gives: bimetallism → Gresham dynamics; the classical gold standard → its collapse 1914/1931; Bretton Woods → Nixon 1971; currency unions and dollarisation. Each is "what happens to a relational value system when you change/remove the designated anchor." Lexical analogues to look for: (a) *editions of the same dictionary over time* — does the Kernel/Core stay stable while MinSets churn (≈ stable real structure, arbitrary nominal anchor)? (b) *Controlled defining vocabularies* (LDOCE's official 2000 words) as a *deliberately imposed* commodity standard — and whether the *empirical* Kernel coincides with the *decreed* defining vocabulary (it doesn't, per Picard/V-L: Kernel ≈ 8–12% of D, the decreed DV is 2000 words — a mismatch exactly like a legal par value diverging from the market price). (c) *Cross-language*: a translation dictionary pegs one language's vocabulary to another's ≈ a fixed exchange rate / dollarisation; what's the analogue of a peg breaking?
- *Feasibility.* Medium. (b) is computable now and is arguably the single most striking concrete result available: *the decreed defining vocabulary is not the actual grounding kernel* — "the gold standard's legal par is not where the market clears." (a) needs multi-edition dictionary data. (c) needs bilingual resources (repo has `Bergh_2025` on building WordNets, `Ghizzota_2025` diachronic). The history itself is read-only colour, but it organises the experiments.

**Tool 5 (lowest, but cheap): the homogeneity-of-degree-zero / Walras's-law framing as the rigorous statement of "meaning has no gold standard."**
- *The transfer.* "There is no absolute price level, only relative prices; demand is homogeneous of degree zero in prices" is the *theorem* the slogan gestures at. State the lexical analogue precisely: a definitional graph plus an embedding determines meanings only up to [some group action]; the choice of anchor is a choice of section of that quotient; nothing in the graph privileges one. Then SMD's lesson: the relational structure is almost-unconstrained, so the *only* universal invariant is the anchor-arbitrariness itself.
- *Feasibility.* This is a writing/framing tool, not code. Zero implementation cost; pays off in the paper's framing and in stating the falsifiers crisply.

## 4. Falsifiers — what would show this is a shallow pun

1. **If the relational structure of money were a complete graph / dense market-clearing system rather than a sparse digraph with an irreducible core.** — *Assessed: this falsifier does NOT fire.* Sraffa's basics/non-basics distinction is precisely an SCC decomposition; the standard commodity is the PF eigenvector of the *basics* block *because* that block is irreducible/indecomposable. The production network is exactly the kind of object (sparse digraph + irreducible core + acyclic periphery) the dictionary-graph literature studies. If anything the structural match is *better* than the prompt feared. (Caveat: a *complete-information exchange economy* with all goods traded against all goods is dense; but the moment you model *production* the input matrix is sparse, and that is the version of economics that matches.)
2. **If "numéraire" were genuinely a single-coordinate normalisation with no FVS content.** — *Partially fires.* For a one-SCC economy, yes, the numéraire is one good and the "FVS" is trivial — the analogy degenerates. The non-degenerate version requires the disconnected-non-basic-subsystems case, where you need one anchor per source component. So: the analogy is shallow *if* you map MinSet ↔ numéraire-good, and deep *if* you map MinSet ↔ minimal-exogenous-price-basket-spanning-a-disconnected-network and use Sraffa's basics/non-basics as the disconnection mechanism. The paper must make this mapping explicitly or a referee will call it a pun.
3. **If the dictionary "cycle" had no fixed-point / self-consistency structure** (e.g. if circular definitions were genuinely vicious and the only sensible move were to break them). — *Does not fire.* The repo's own `Levary_2012` line and the Massé framing both treat the Core as a coherent self-referential structure, not garbage; and the simplest "meaning = pooled definers' embeddings, iterated" map plausibly has a fixed point. (Open: is it unique? If the map is a contraction the interior multiplicity collapses — that weakens, but does not kill, the "many consistent interpretations" half of the analogy; the *grounding* multiplicity survives regardless.)
4. **If the psycholinguistic gradient had no economic shadow whatsoever** — *fires weakly.* It largely doesn't have one; this is a real thinness, not fatal (the analogy doesn't *need* AoA, but a critic can point to it as "the dictionary object is richer; you're projecting away the interesting part").
5. **If someone has already published this.** — Searched both directions (§2); found the Sraffa–Wittgenstein thread and the "representational currency" dead metaphor but no paper making the FVS ↔ numéraire / Harnad ↔ chartalism link. Could exist unindexed; medium-low probability.
6. **Sign/weighting prerequisite.** — Porting Sraffa's *spectral* construction needs a non-negative edge weight on the definitional graph; if no defensible weight exists the PF-eigenvector "canonical MinSet" is arbitrary in its own way. *Mitigation:* unweighted (all-ones) gives plain eigenvector centrality of the Core, which is a perfectly defensible default; the dependence-on-weighting is honest and parallels Sraffa's dependence-on-"invariant-to-distribution."

Net: the analogy survives the prompt's headline falsifier (sparse-digraph-vs-complete-graph) cleanly; its genuine soft spots are (a) MinSet-as-FVS vs numéraire-as-coordinate (handled by the right mapping), (b) the missing psycholinguistic shadow, (c) static-vs-dynamic. None is fatal; all should be stated in the paper.

## 5. The paper that should exist

**Title:** *Meaning Has No Gold Standard: The Symbol-Grounding Problem Is the Numéraire Problem.*

**Venue:** *Cognitive Science* or *Topics in Cognitive Science* (where Vincent-Lamarre et al. published) for the cognitive-science readership; or *Synthese* / *Mind & Language* for the philosophy angle; an economics-theory venue (e.g. *Journal of Economic Methodology*) would reach the other half but the centre of gravity is the lexical/cognitive side. Co-authored across an econ theorist and a lexical-graph person — the point *is* the bridge.

**Thesis:** Recursive definability in a dictionary and relative-price determination in a commodity economy are the same formal situation — a relational value system homogeneous of degree zero, with no intrinsic units, in which "grounding" is a choice of normalisation (numéraire). Three consequences follow that neither literature has drawn alone: (1) the dictionary literature's "many MinSets, none canonical" *is* Walras's numéraire-arbitrariness, and Sraffa's standard commodity supplies the missing algorithm for a *spectrally canonical* MinSet (left Perron–Frobenius eigenvector of the irreducible Core, since the Core is the dictionary's "basic-commodities" block); (2) general-equilibrium fixed-point existence is the missing positive account of *why a circular definitional Core is self-consistent rather than viciously regressive*, with multiplicity of equilibria mirroring Quinean indeterminacy and multiple MinSets; (3) the Harnad / distributional-semantics dispute over whether meaning *needs* an exogenous anchor is, structure for structure, the hard-money / chartalist (MMT) dispute over whether money does — and monetary history (gold standard → 1971 → fiat) is a worked natural experiment in what happens when you swap or remove the anchor.

**The one figure/theorem that carries it:** A single side-by-side figure. Left panel: a dictionary graph drawn as Rest → Kernel ⊃ {Core (one big SCC) ∪ Satellites}, with one MinSet highlighted, captioned with Vincent-Lamarre's "every dictionary has a huge number of MinSets." Right panel: a Sraffa production network drawn as non-basics → basics block (irreducible), with the standard-commodity eigenvector highlighted, captioned `w = 1 − r/R` and "any commodity can serve as numéraire; the standard commodity is the distinguished one." Same picture, twice. The accompanying **proposition** (the load-bearing formal claim): *Let G be a definitional digraph whose Core C (largest source SCC of the Kernel) carries non-negative edge weights. Then (i) C is the unique maximal irreducible sub-structure on which a Perron–Frobenius eigenvector is defined — the lexical analogue of Sraffa's basic-commodity block; (ii) greedily deleting vertices of G in decreasing order of left-PF-centrality of C until G is acyclic yields a feedback vertex set ("the standard MinSet") that is canonical given the weighting; (iii) the choice of weighting is the lexical analogue of the choice of "invariant-to-distribution," and no weighting-independent canonical MinSet exists — the lexical statement of numéraire-arbitrariness.* Then the empirical kicker, runnable on the repo's existing OEWN kernel pipeline: compute the standard MinSet and test whether it coincides with the high-frequency / early-acquired MinSet; report the (mis)match — either way it speaks to Harnad's residual ("structural canonicity ≠ cognitive/semantic canonicity, just as a self-consistent fiat price level ≠ intrinsic value").
