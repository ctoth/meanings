## 0. What this is, in one paragraph

The project asks *how circular is a curated dictionary, and what is the minimal set of words you would have to fix from outside so that every other word's definition unfolds acyclically?* — formalized as the feedback-vertex-set / Kernel-Core-Satellites-MinSet decomposition of the definition digraph, applied to Open English WordNet (`oewn:2024`), with Harnad's symbol-grounding problem as the standing reason the graph result is **not itself a semantics** (a MinSet is not a set of human semantic primitives; a graph node is not a human word — see §4). The intended deliverable is the "Up-Goer" vocabulary — the words the *definitional wiring* of this dictionary leans on irreducibly — but the honest scope is "the non-circular core of *this curated dictionary*," not "the structure of English / of meaning"; for word meaning in general, large-corpus / LLM methods have the data and this project does not (it uses them — LGDE, OpenGloss — where coverage matters; see §4, §6). Three layers of work sit on the base kernel tooling: (a) a **cross-domain ("Swanson") pass** that tested whether the dictionary-kernel problem is a known problem in disguise across economics / network control / ecology / category theory; (b) an **argumentation-framework reframing** — the definition digraph is a bipolar AF / ADF, the MinSet is a minimal enforcement set, the Kernel-vs-loop-ecology split is grounded-vs-preferred semantics — which is, on the current `lemma::pos` graph, mostly a **useful relabeling** (see §2, §9) whose net-new content only materializes at the sense level; (c) an **ingestion redesign** — `form → token → reading → sense → IC → admission` as a typed defeasible system — which a first prototype this round partially realized (a support graph + tag-filtered exports; not yet the attack layer or the admission theory — see §3). Lineage: `Masterman 1961 → Harnad 1990 → Massé 2008 / Picard 2013 / Vincent-Lamarre 2014 → LGDE 2025 / OpenGloss 2025` (`reports/synthesis-minimal-core-to-expansion.md`).

## 1. What the cross-domain (Swanson) pass found

Scoreboard (`reports/swanson-synthesis.md`, per-line `reports/swanson-*-findings.md`, `reports/codex-swanson-review.md`; Kernel/seed numbers post the self-loop fix per `reports/stale-numbers-audit.md` / `reports/self-loop-fix-impact.md`):

- **#5 Perron–Frobenius valuation — strongest link, naive form falsified.** The same matrix object (the dominant eigenvector of a non-negative irreducible relational matrix) is independently rediscovered as Sraffa's standard commodity (the Perron eigenvector of the irreducible "basics" input-output block — and the basics/non-basics split *is* an SCC / Frobenius-normal-form idea), the Markov stationary distribution, PageRank and its bibliometric/sociological ancestors (Hubbell, Pinski-Narin, Bonacich, Katz, HITS), and the leading singular vectors of LSA's co-occurrence matrices — with near-empty cross-citation (Bidard-Erreygers-Parys "All but one"; Potron 1911 ignored ~90 years). **On the OEWN graph the spectral object is deflationary:** authority (forward) PageRank ranks definitional sinks (`magnificat`, `niobe`, …) at the top, not foundational vocabulary; reverse-PageRank (PageRank on the transpose) *does* surface the right genus words qualitatively (`act, degree, time, event, part, place, can, …`; `large`→27/160,010, `body`→29, `small`→66) but ρ with the FVS degree-key is only ~0.37 over the Kernel, ρ with out-degree is 0.99 full / 0.80 Kernel, and a degree-preserving edge-swap null recovers ~0.61 of the real ranking — **reverse-PageRank is out-degree spectrally laundered.** Outputs: a history-of-science "convergent rediscovery" paper, and a CL paper ("The Wrong Eigenvector"). The honest version (math facet): "same matrix algebra under an irreducibility/normalization problem," not "the same idea in every field" — what *flows* differs (value, probability, prestige, co-occurrence mass, definitional productivity). *(Note: this same object being LSA/PageRank-shaped is also self-incriminating for the "we are not distributional semantics" posture — see §4, §9.)* (`reports/synthesis-facet-math.md`, `reports/spectral-valuation-oewn.md`, `reports/swanson-perron-frobenius-findings.md`.)
- **#3 Controllability / driver nodes — a divergence, not an identity, and a cleaner link underneath it.** FVS-grounding (cycle-breaking / well-foundedness) and structural-controllability driver nodes (Hopcroft-Karp maximum matching / dilation under linear-integrator dynamics — Liu-Slotine-Barabási 2011) are genuinely different objects with predictably different selections: post-self-loop-fix, full digraph 118,744 drivers (74.2%), overlap with the 5,044-node `exact-small-greedy` FVS seed = 2,207, Jaccard **0.018**; Kernel subgraph 3,916 drivers (21.6%), only 316 in common, Jaccard **0.037**; driver-not-grounder = morphological derivatives + the numeral/proper-noun acyclic frontier, grounder-not-driver = abstract relational vocabulary. *(These are the post-fix figures from `reports/swanson-synthesis.md`; `reports/synthesis-inventory.md` §1.4 still carries the pre-fix ones — 2,370-node seed, Jaccard 0.012/0.052 — which are stale.)* The *contrast* is the value. The genuinely under-exploited bridge is **FVS-control in biology** (Mochizuki-Saito 2010 "informative nodes"; Fiedler-Mochizuki 2013 I & II; Zañudo-Yang-Albert PNAS 2017): a feedback vertex set for control of *nonlinear* dynamical networks, no contact with the dictionary-grounding literature that also uses FVS, and its empirical FVS-control-vs-matching-control split (1–18% vs 75–96% of nodes for gene-regulatory nets) puts the OEWN definition graph (~3.15% FVS seed = 5,044/160,010, vs ~74% matching drivers) inside the gene-regulatory FVS regime. Six papers added to the collection. (`reports/swanson-controllability-findings.md`, `papers/index.md`, `reports/maximum-matching-oewn.json`.)
- **#2 Core–satellite ecology — falsified.** Same name, zero cross-citation, but the bimodality falsifier fired: OEWN out-degree is log-series / species-abundance shaped (heavy zero spike + monotone tail, no second hump), Core and Satellite have near-identical out-degree distributions, so the lexical split is *condensation topology* (source SCC vs downstream SCC inside the Kernel), not Hanski's common-vs-rare. Only the weak diachronic form survives (colonization-extinction of the defining vocabulary across editions) and it needs LDOCE-revision data; the strong rescue-effect prediction is contradicted by current data. (`reports/swanson-synthesis.md` §Ecology.)
- **#1 Money / numéraire — demoted.** The brief conflated four things; subsumed by #5. The one tight bridge — Sraffa's standard commodity = the Perron eigenvector of the irreducible basics block — yields the **weighted standard-MinSet theorem** (fold into the lead paper): for an irreducible weighted Kernel `K` with PF vector `π` and any positive grounding-cost `g(v)`, set `c(v) = g(v)/π_v`; a `c`-minimum FVS is renormalization-invariant and is a Sraffa-style *standard* MinSet — canonical relative to `A_K` and `g`, not semantically ultimate. Two independent runs converged. Don't lead with the money framing. (`reports/swanson-synthesis.md` §Money.)
- **#4 Yoneda ↔ Harnad — compatible (Resolution A), not contradictory.** Yoneda determines an object *within a fixed category*; Harnad's point is the ambient category is not given a priori for a cognitive agent — it must be grounded into existence non-symbolically. Grounding constructs/selects the base category; once it's fixed, structural identity does real work inside it. MinSet ≈ generating set; MinSet non-uniqueness ≈ presentation non-uniqueness. The symmetry rider (both philosophy facets): a thoroughgoing structuralist who dissolves grounding in cognitive semantics owes mathematics the same story — Benacerraf's access problem is Harnad's question in mathematical clothing. The dictionary graph is only an *analogy* to a category (its edges don't supply identities/composition/functoriality) — keep that in scope. (`reports/synthesis-facet-philosophy-{codex,gemini}.md`, `reports/swanson-yoneda-harnad-findings.md`.)

**The empirical adjudication (run this round).** Psycholinguistic regression (`reports/psycholinguistic-regression-findings.md`, run on the *pre-self-loop-fix* Kernel — verdicts not numbers-sensitive): joining SUBTLEX-US Zipf / Kuperman AoA / Brysbaert concreteness onto the graph, the **psycholinguistic block adds ≤ 0.01 ΔR²/ΔAUC over the structural block** for every layer/membership outcome; the Vincent-Lamarre "deeper layers = later-acquired" effect vanishes once you control for structure; reverse-PageRank / the FVS seed add ≤ +0.03 incremental R² over `log(out-degree)` for the three norms. This **refutes the strong claim** — no large independent extra-graph residue these norms detect that the bare relational structure obviously misses. It does **not** establish "meaning is Yoneda-complete," because of the binding **lexicographer's confound**: dictionaries are written *for learners*, so concrete/early/frequent words become definers *because* readers are expected to know them — which *creates* the structural features. "Block 2 adds nothing over block 1" is equally consistent with "meaning is relational" and "the graph was built from psycholinguistic salience, so it screens it off" — same regression signature, opposite causation; the regression cannot tell which way it runs. The **ranking-semantics follow-up** (`reports/ranking-valuation-oewn.md`) confirms the deflation from a third angle: every gradual argumentation semantics tried (h-categorizer, categoriser, burden, counting; both orientations) is an arithmetic re-skin of degree on the bare `lemma::pos` digraph — best incremental R² over `log(out-degree)` ≈ +0.023 (kernel-subgraph, burden/concreteness, on a ≈0 baseline; the full-graph pass was iteration-capped and those numbers live only in `reports/ranking-valuation-oewn.json`) — and the *sign is wrong* for "foundational" under the attack reading (a heavily-used genus word like `act::n` has many attackers → low score; these rank dictionary leaves high). Methodological note: `argumentation.ranking` is for *attack* graphs; reading definition edges as attack ranks leaves as foundations — the sign-correct import is the *bipolar/support* side over the sense graph (not yet run). **Cumulatively: three "is there structure beyond degree / beyond the relations?" probes, three "no" verdicts — which is the distributional thesis accumulating evidence in the project's own logs. The synthesis takes this seriously in §4, not as a foil.**

## 2. The argumentation-framework reframing, and the scaling result

**The reframing** (`reports/sibling-tools-connection.md`): the definition digraph *is* an instance of "what survives when support is circular and the verdict is underdetermined," which is what formal argumentation / belief revision / defeasible logic formalize — and Q owns reference implementations of all three. **Caveat up front (Gemini's review, conceded — see §9): on the current `lemma::pos` graph this reframing is mostly a relabeling.** The "theorems" below are real but not *new* — they restate Massé 2008 / Dvořák-Pichler-Woltran in argumentation vocabulary. The reframing earns net-new content only at the sense level (non-empty attack edges) — which has not been built yet (agenda #3).

- A dictionary graph is a **bipolar AF / ADF**: definition edges are *support*, each word an acceptance condition over its definiens. *But*: on the `lemma::pos` graph the support-reading defeat relation is *empty* (`argumentation_bridge.py`), so the library's bipolar grounded semantics is the identity function there — the actual cycle-breaking is done by `compute_kernel`/`solve_minset`, not by argumentation semantics. The bipolar/ADF framing buys something only once rival senses of a form *attack* each other — which requires the sense-level graph (§3) and is the one place the framing is not a relabeling.
- **MinSet = a minimal-enforcement set** (`enforce_skeptical`) and an **FPT backdoor parameter** (Dvořák-Pichler-Woltran). Honest status: this is Massé's already-known FVS-grounding-set theorem restated in AF vocabulary plus the already-known FPT-in-backdoor-size result; **no new mathematical content** — it's a translation dictionary between "feedback vertex set" and "enforcement/backdoor set." Useful (it imports the FPT machinery as a *frame*), not a discovery. **"Many MinSets, none privileged" = stable-extension multiplicity *per 2-cycle / per SAT-SCC*** — and crucially **this identity does not lift to the OEWN Kernel: the whole Kernel AF is UNSAT for stable extensions** (z3, ~8 s; see below), so there is no stable extension whose outsider set the MinSet could be. The "many MinSets = many stable extensions" story, which was the headline of the reframing, *collapsed on contact with the data*; what's left of the connection at the lemma level is "MinSet = FVS = backdoor" (a relabeling) and "Kernel-vs-loop = grounded-vs-preferred" (a mnemonic with no computational teeth yet — preferred semantics has produced no word set the loop-ecology analysis hadn't). The math facet's read of the multiplicity is the durable one: "a family of admissible grounding choices; ranking them requires an explicit cost function (psycholinguistic plausibility / pedagogical utility / sensorimotor accessibility / cross-dictionary stability — 'smallest' ≠ 'best grounded')."
- Dictionary editions = AGM belief revision; "how foundational is this word" = epistemic entrenchment / Spohn rank — *framework borrowed, library can't carry it* (`../belief-set` hard-caps `max_alphabet_size = 16`; build the OCF from the graph yourself). Three unrelated "kernel"s — meanings-repo Kernel, AGM "kernel contraction" (Hansson), `af_revision.py`'s "kernel" (Baumann) — coincidence, not a bridge.
- Polysemy / WSD = defeasible reasoning; a circular ungrounded definition produces `UNDECIDED`, not an error — Harnad's "recursive definability ≠ meaning" mechanized.

**The scaling result (this round) — what actually scaled.** *The grounded-semantics scaling blocker is retired in code* (was a quadratic library implementation; is now a linear one). The *harder* semantics scale on *this graph's structure* via SCC-condensation + z3, but preferred-extension enumeration at scale was **not** run — so "argumentation can't scale is retired" is true for grounded and for stable-*existence*, an over-claim for preferred (§9).
- The patched `argumentation.dung.grounded_extension` (upstream `4a1c31cc` — confirmed: `import argumentation; grounded_extension` on the *installed pinned* version is the labelling rewrite, and computes a 100k-node / 114k-edge synthetic graph in 0.5 s) computes the grounded extension over the full 160,010-node OEWN attack-AF in **~1.5 s** (verifier, median of 6, measured against the local `argumentation` working tree pre-push — `reports/verify-argumentation-perf-fixes.md`) **/ ~4.3 s** in the dispatcher run that imports the installed dependency (`reports/argumentation-dispatch-oewn.md`) — same linear algorithm, the ~3× spread is host/load + the larger edge count; both vastly under the pre-fix >200 s-and-killed. *(The verifier's 806-tests-pass + bit-exact-equivalence checks were on that local working tree; the chain of custody from "verified" to "pinned `4a1c31cc`" was closed by the spot-check above — the installed pin has the labelling implementation.)* The grounded extension (5,043 nodes under the attack reading) is *not* the Kernel decomposition under either edge reading — and that's the expected answer (an FVS member is grounded-from-outside; the grounded extension is what's forced from inside; overlap ≈ 2).
- **The Kernel AF has no stable extension** — z3 decides the whole 18,151-node Kernel attack-AF UNSAT in ~8 s, the 8,138-node giant core SCC UNSAT in ~3.3 s; of ~693 non-singleton Kernel SCCs, 630 SAT / 63 UNSAT (odd cycles). Under the pure-attack reading the OEWN definition graph admits no fully self-consistent stance — you *must* ground something.
- The **SCC + z3 + FVS-backdoor dispatcher** (`src/meanings/argumentation_dispatch.py`, new this round): condense into SCCs, propagate forced-OUT along the condensation DAG, decide each SCC with a per-SCC oracle (brute-force ≤ 12 nodes / z3 above / an FVS-backdoor hook for the giant core), and — the practical win — **cache the oracle by SCC isomorphism class: the 9,139 Kernel SCCs collapse to 41 distinct classes, 99.6 % cache hit rate** (real engineering value for the thousands of tiny satellite SCCs). It *re-runs* the bridge's UNSAT verdict via the *same* per-SCC z3 oracle on the *same* giant SCC (so it's a faster re-run with the SCC front-end the bridge lacked, not an independent solver corroborating UNSAT) in ~12 s. Exposes `dispatch_stable` / `stable_exists` / `credulous_accepts` / `skeptical_accepts` / `grounded` (delegates to the linear upstream) / `minset_structure`. Caveats: the FVS-backdoor is wired but defers to z3 (the giant SCC's FVS is too large for `2^|FVS|`); `stable_exists` is a greedy topological sweep — definitive for the OEWN Kernel (its UNSAT SCCs are UNSAT regardless of context), could over-report UNSAT in pathological context-dependent cases (the exact-count path uses full DAG DP without that issue); **preferred-extension enumeration for the giant core is not attempted** (Π₂ᵖ-complete; un-scaled). (`reports/argumentation-dispatch-oewn.md`.)
- The **`gunray` UNDECIDED demonstrator** (`scripts/gunray_grounding_demo.py`): a toy circular definition (`a -< b`, `b -< a`, no facts) → both `UNDECIDED`; add one grounding fact → the chain resolves to `YES`; the dialectical tree rendered. Demonstrated on a real ~9-word strongly-connected slice of the OEWN *lemma-level* Kernel (the `build_lemma_graph` graph — 151,622 nodes / 25,185-node Kernel, *not* the `paper-wordnet` graph used everywhere else — a Greek-mythology definitional loop), and on a *hand-built* `gunray` theory illustrating the polysemy case (`no` negation vs Nobelium, with hardcoded rules — illustrative, not derived from the data). This is "recursive definability ≠ meaning" in working code, a paper figure — and a *demonstrator on a hand-picked slice / hand-built theory*, not a result on the OEWN graph. (`reports/gunray-grounding-demo.md`.)

**The complementarity** (`reports/synthesis-facet-engineering.md` §1.2): `../argumentation` provides the *semantics* but no graph toolbox; `meanings` provides the *graph toolbox* but no semantics solver; `argumentation_bridge.py` is the seam, `argumentation_dispatch.py` the scale layer. None of the three sibling libraries is a production graph algorithm on a real vocabulary — `gunray` enumerates argument subsets, `belief-set` enumerates `2^n` worlds, `argumentation`'s enforcement is a brute-force oracle — so the production path is: `meanings` machinery for the graph skeleton + the sibling libraries (and their semantics) as *per-SCC / per-profile oracles* and as the *conceptual type system*.

## 3. The ingestion redesign — `lemma::pos` is the wrong granularity, and a first prototype ran

**The problem** (`reports/synthesis-facet-datamodel-{claude,gemini}.md`, `notes/upgoer-identity-clusters.md`). The `paper-wordnet` graph is one node per `lemma::pos` with the *first* synset that has a non-empty gloss as the representative — a WordNet ordering decision determines whether `no::n` enters as "the negation" or "Nobelium." This conflates **form** (`color` vs `colour`; `No` vs `no`, which `normalize_lemma`'s lowercasing already wrongly merges), **sense**, and **identity cluster (IC)**. Concrete, measurable damage: `no::n` = Nobelium pulled in; **3,413 gloss self-loops** (many artifacts — a gloss for `violin::n` saying "violin" means the *intended sense*, not literal self-definition); spelling-variant inflation; constructions flattened; indexical signal (`warsh` indexes region/class) with nowhere to go.

**The target data model** (the twin drafts converge; Claude's is implementation-grade with full dataclass schemas + the `EvidenceKind`-makes-vector-soup-unrepresentable mechanism, Gemini's the executive summary): a typed stack `Form → TokenOccurrence → Reading → Sense → IC` plus `Construction`, `Metadata`, `Provenance`, `AdmissionPolicy`, with a shared 9-tag `Lexicality` enum (`lexical_word` / `symbol_code` / `abbreviation` / `proper_name` / `taxon` / `chemical` / `technical` / `phrase` / `idiom` / `uncertain`). Definition edges = `supports` between resolved **Sense** nodes (the honest bipolar-AF/ADF — *not* the `lemma::pos` graph); rival senses of a form `attack` each other (defeasible WSD, `gunray`-shaped, the dialectical tree = the rationale); IC merge = a `belief-set` profile merge that **keeps both forms** with per-merge provenance — never canonicalization; referential vs indexical separated *structurally*. The two deliverable surfaces: the **strict typed seed** (the FVS / grounded extension restricted to typed-lexical ICs — a research artifact) vs the **human Up-Goer list** (the admitted extension of a defeasible admission theory over typed IC nodes) — *different objects, not subset-related; "graph necessity is not human-primitive admission."*

**What the first prototype actually did this round** (revised after Codex's review — see §9). `src/meanings/lexicality.py` (the ingestion-time *rule-based* classifier), `src/meanings/identity_clusters.py` (a 7-pair hand-coded spelling-variant whitelist over 14 forms), `build_sense_level_paper_wordnet_graph` (sense nodes carrying lexicality tag + source synset + IC id; **support edges only — no attack-edge layer yet**; gloss-token resolution excludes the head sense from the candidate set and skips on self-reference), `scripts/sense_ingestion_rebuild.py`, `notes/sense-ingestion-design.md`. Result: sense-level graph = **212,478 sense nodes / 418,094 edges; Kernel 12,142** (`exact-small-greedy`; vs the lemma-level 18,151), residual cyclic SCCs after the seed = **0** (acyclic closure holds). **Zero literal emitted gloss self-loops** (vs 3,413 at lemma level) — but read this precisely: it means "no head sense was linked to itself after the resolver excluded the head from its own candidate set and skipped 1,496 self-references" — an adjacency fact under a skip-on-self resolver, *not* a validated WSD result. **4,562 short non-lexical artifacts** (the `no::n`=Nobelium / `s::n`=sulfur class) "quarantined/excluded" — but these are *un-audited rule-pile outputs* (no measured precision/recall; the classifier's near-bottom default sends every normal-POS sense to `lexical_word`, so the `uncertain` tag is practically unreached; the short-token whitelist's status is unclear — the rebuild output tags *zero* short tokens `lexical_word`, which may mean the whitelist isn't producing admissions). **7 spelling-variant ICs over 14 forms** "merged" — a hand-coded seed fixture, not a merge *method* (it preserves aliases and provenance, which is good, but it doesn't discover merges, compare glosses, or adjudicate rival senses; calling it "IC merge as belief-merge" over-dignifies a whitelist). Exports: `data/oewn-sense-strict-seed.json` (834 lexical-IC seed — the script computes `analyze_kernel` on the *raw all-sense graph* then filters seed nodes to lexical, **not** the typed-lexical-IC-projected Kernel the data-model facet's prediction was about; which of the two §6-agenda definitions the script implements is unverified — `reports/synthesis-facet-datamodel-claude.md` §8) and the human Up-Goer IC vocabulary (121,375 admitted ICs — these are *the ICs with ≥1 lexical-word/phrase/idiom sense*, i.e. a **lexicality-tag filter**, NOT the admitted extension of a defeasible admission theory; no `AdmissionPolicy`/`gunray` evaluation is run; gitignored, 35 MB, regenerable).

**The honest statement of what the rebuild demonstrated** (Codex's wording, adopted): a first sense-level prototype built a support graph over all OEWN senses (a genuine improvement over the first-representative-synset collapse), attached metadata, eliminated literal emitted self-loops under a skip-on-self resolver, and produced two tag-filtered export files. It did **not** demonstrate validated lexicality classification, real WSD, an IC belief-merge *method*, an end-to-end admission theory, the rival-sense attack layer, or the typed-lexical-IC Kernel. And the Kernel-shrinkage 18,151 → 12,142 is **not** evidence of "dissolved artifacts" on its own — beyond the different node surface (212k sense nodes vs 160k lemma nodes), the sense graph has ~2× fewer **edges per node** (1.97 vs 4.24) because **54 % of gloss-token candidate matches (499,860 / 925,283) were dropped as ambiguous** by the resolver; a smaller Kernel on a graph where you discarded half the edges is partly "we dropped the edges that would have formed cycles," not only "the artifacts dissolved." The load-bearing, defensible claim is narrow: *literal gloss self-loops are eliminable by resolving same-surface gloss occurrences away from the head sense, and the resulting sense graph still has acyclic definitional closure after a (non-exact) seed* — an honest, falsifiable result about a parsing artifact in a specific resource, with an edge-budget-controlled comparison still owed (agenda #5).

## 4. The distributional question, and where the project over-/under-claims

**On "reinventing distributional semantics" (claude -p's review, half-conceded — §9).** The project's three empirical results this round all say "meaning is, on this artifact, largely relational" — *that is the distributional thesis*, and the synthesis should stop posturing against it: **concede it.** What the project should *not* concede is the conflation of two different things. (i) The *thesis* "word meaning is largely relational" — the data supports it; agreed. (ii) The *artifact* "an opaque, undirected, unaudited vector blob" — rejected, on two grounds the embedding instance genuinely lacks: **directedness** (a corpus / an embedding has no `must-know-X-before-Y` arrow — so it cannot even *ask* "is this lexicon circular? what is the minimal external grounding set?"; the dictionary definition graph is a directed dependency structure and the FVS/well-foundedness layer is *not* reinvented distributional semantics — it has no distributional analog) and **inspectability** (provenance, derivation chains, "why is this word foundational," "what changes if you ground a different word" — queries an embedding can't answer at all). The right slogan: *we agree meaning is largely relational; we disagree that an opaque undirected embedding is the right way to represent the relations, and the dictionary instance carries a directed-dependency question the embedding instance doesn't have.* Honest admissions that follow: the typed system's first head-to-head (agenda #4, run this round — `reports/lexicality-headtohead.md`: the rule-based lexicality classifier vs a TF-IDF-gloss + logistic-regression baseline, on a stratified ~1,200-sense gold set) came out a **split, not a clean win** — overall macro-F1 essentially tied (rules 0.739 vs TF-IDF 0.744), micro-F1 the bag-of-words ahead (0.760 vs 0.796), but the rules **dominate the surface-form-bound subset** (short-token / symbol-code: macro-F1 0.580 vs 0.296 — the gloss of `s`-as-sulfur describes sulfur, so a gloss bag-of-words has no signal there) and **lose the cue-rich subset** (taxa / chemicals: 0.256 vs 0.454). So the refined statement is "the typed system is *more auditable* across the board, and *better* on the subset where the symbolic form-pattern carries the signal and the distributional view doesn't" — and the honest design conclusion is a **hybrid** (keep the surface-pattern rules for short tokens / symbol-codes; replace the taxon/chemical/technical *gloss-keyword templates* with a small trained gloss classifier where bag-of-words wins). That is the project taking the distributional side seriously where it actually helps, not as a foil. For word meaning *in general* (not "is this dictionary circular"), large-corpus / LLM methods have the data and the project uses them where coverage matters (LGDE for outward growth, OpenGloss as a future substrate); and the lexicographer's confound, taken to its conclusion, makes the dictionary graph plausibly *a small expert community's folk model of what learners already know* — which is a real, live reading of the *whole* program, not just a caveat on one regression. The narrower README framing ("how circular is a dictionary?") is the defensible scope; §0 has been demoted to it.

**Can defend** (the philosophy facets' verdict, adopted): a dictionary graph makes recursive definability measurable; grounding sets are feedback vertex sets; the Kernel/Core/Satellite/MinSet anatomy is stable and useful; loops are semantic structure as well as obstacles; psycholinguistic salience and graph structure are largely *co-extensive* on the current OEWN artifact (which way the causation runs is undetermined — see "Should not claim"); `UNDECIDED` is the right formal status for circular ungrounded definitions; *literal* gloss self-loops are eliminable by sense-level resolution (the prototype showed this — pending the agenda-#7 audit). **Should not claim:** that a MinSet is a set of ultimate semantic primitives; that recursive definability is intrinsic meaning; that degree / PageRank / ranking semantics / FVS membership gives a deep continuous measure of groundedness on the bare `lemma::pos` graph (every such score collapsed to degree, with the wrong sign under the attack reading); that the psycholinguistic regression proves meaning is relationally complete (the lexicographer's confound is fatal — the structure may mirror the norms *because* the graph is a cultural artifact made by humans for humans); that a raw graph node is already a human word; that the sense-level prototype has *validated* lexicality / a real WSD step / an IC-merge method / an admission theory. The strongest position is modest but durable: dictionary graphs **locate the places where a symbolic lexicon cannot justify itself from within**; grounding and coherence are not enemies.
