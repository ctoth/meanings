## 0. What this is, in one paragraph

The project asks *how small is the non-circular core of a dictionary?* — formalized as the feedback-vertex-set / Kernel-Core-Satellites-MinSet decomposition of a definition digraph, applied to Open English WordNet (`oewn:2024`), bounded above by Harnad's symbol-grounding limit. The deliverable is the "Up-Goer" vocabulary — the words you'd need to bootstrap English, done honestly. Three layers of work now sit on the base kernel tooling: (a) a **cross-domain ("Swanson") pass** that tested whether the dictionary-kernel problem is a known problem in disguise across economics / network control / ecology / category theory; (b) an **argumentation-framework reframing** — the definition digraph is a bipolar AF / ADF, the MinSet is a minimal enforcement set, the Kernel-vs-loop-ecology split is grounded-vs-preferred semantics — with the sibling tools `../argumentation`, `../belief-set`, `../gunray` as the (mostly demonstrator-tier) machinery; (c) an **ingestion redesign** — `form → token → reading → sense → IC → admission` as a typed defeasible system, which fixes the `lemma::pos` artifacts and is the actual data model the argumentation reframing wants. Lineage: `Masterman 1961 → Harnad 1990 → Massé 2008 / Picard 2013 / Vincent-Lamarre 2014 → LGDE 2025 / OpenGloss 2025` (`reports/synthesis-minimal-core-to-expansion.md`).

## 1. What the cross-domain (Swanson) pass found

Scoreboard (`reports/swanson-synthesis.md`, per-line `reports/swanson-*-findings.md`, `reports/codex-swanson-review.md`; numbers post the self-loop fix per `reports/stale-numbers-audit.md`):

- **#5 Perron–Frobenius valuation — strongest link, naive form falsified.** The same matrix object (the dominant eigenvector of a non-negative irreducible relational matrix) is independently rediscovered as Sraffa's standard commodity (the Perron eigenvector of the irreducible "basics" input-output block — and the basics/non-basics split *is* an SCC / Frobenius-normal-form idea), the Markov stationary distribution, PageRank and its bibliometric/sociological ancestors (Hubbell, Pinski-Narin, Bonacich, Katz, HITS), and the leading singular vectors of LSA's co-occurrence matrices — with near-empty cross-citation (Bidard-Erreygers-Parys "All but one"; Potron 1911 ignored ~90 years). **But on the OEWN graph the spectral object is deflationary:** authority (forward) PageRank ranks definitional sinks (`magnificat`, `niobe`, …) at the top, not foundational vocabulary; reverse-PageRank (PageRank on the transpose) *does* surface the right genus words qualitatively (`act, degree, time, event, part, place, can, …`; `large`→27/160,010, `body`→29, `small`→66) but ρ with the FVS degree-key is only ~0.37 over the Kernel, ρ with out-degree is 0.99 full / 0.80 Kernel, and a degree-preserving edge-swap null recovers ~0.61 of the real ranking — **reverse-PageRank is out-degree spectrally laundered.** Outputs: a history-of-science "convergent rediscovery" paper, and a CL paper ("The Wrong Eigenvector"). The math facet states the honest version: "same matrix algebra under an irreducibility/normalization problem," not "the same idea in every field" — what *flows* differs (value, probability, prestige, co-occurrence mass, definitional productivity). (`reports/synthesis-facet-math.md`, `reports/spectral-valuation-oewn.md`, `reports/swanson-perron-frobenius-findings.md`.)
- **#3 Controllability / driver nodes — a divergence, not an identity, and a cleaner link underneath it.** FVS-grounding (cycle-breaking / well-foundedness) and structural-controllability driver nodes (Hopcroft-Karp maximum matching / dilation under linear-integrator dynamics — Liu-Slotine-Barabási 2011) are genuinely different objects with predictably different selections: full digraph 118,744 drivers (74%), Jaccard with the FVS seed ≈ 0.02; Kernel subgraph drivers comparable in *size* to the seed but Jaccard ≈ 0.04; driver-not-grounder = morphological derivatives + the numeral/proper-noun acyclic frontier, grounder-not-driver = abstract relational vocabulary. The *contrast* is the value. The genuinely under-exploited bridge is **FVS-control in biology** (Mochizuki-Saito 2010 "informative nodes" / "linkage logic"; Fiedler-Mochizuki 2013 I & II; Zañudo-Yang-Albert PNAS 2017): that literature uses a feedback vertex set for control of *nonlinear* dynamical networks, has no contact with the dictionary-grounding literature that also uses FVS, and its empirical FVS-control-vs-matching-control split (1–18% vs 75–96% of nodes for gene-regulatory nets) puts the OEWN definition graph (~1.5% FVS seed vs ~74% matching drivers) squarely in the biological-network regime. Six papers added to the collection. (`reports/swanson-controllability-findings.md`, `papers/index.md`, `reports/maximum-matching-oewn.json`.)
- **#2 Core–satellite ecology — falsified.** Hanski's core/satellite hypothesis (ecology) and the dictionary Core/Satellite decomposition share a name and have zero cross-citation (a canonical Swanson signature) — but the bimodality falsifier fired: OEWN out-degree is log-series / species-abundance shaped (heavy zero spike + monotone tail, no second hump), and Core and Satellite have near-identical out-degree distributions, so the lexical split is *condensation topology* (source SCC vs downstream SCC inside the Kernel), not the common-vs-rare distinction that *is* Hanski's. Only the weak diachronic form survives (colonization-extinction of the defining vocabulary across dictionary editions) and it needs LDOCE-revision data; the strong rescue-effect prediction is contradicted by current data. (`reports/swanson-synthesis.md` §Ecology.)
- **#1 Money / numéraire — demoted.** The brief conflated four things (numéraire-as-gauge / gold-standard-as-convertibility / Harnad grounding / Sraffa standard commodity); subsumed by #5. The one tight bridge — Sraffa's standard commodity = the Perron eigenvector of the irreducible basics block — yields the **weighted standard-MinSet theorem** (fold into the lead paper): for an irreducible weighted Kernel `K` with PF vector `π` and any positive grounding-cost `g(v)`, set `c(v) = g(v)/π_v`; a `c`-minimum FVS is renormalization-invariant and is a Sraffa-style *standard* MinSet — canonical relative to `A_K` and `g`, not semantically ultimate. Two independent runs (in-repo + an external deep-research thread) converged on this. Don't lead with the money framing. (`reports/swanson-synthesis.md` §Money; `reports/swanson-money-numeraire-findings.md`, `...-deepresearch.md`.)
- **#4 Yoneda ↔ Harnad — compatible (Resolution A), not contradictory.** Yoneda determines an object *within a fixed category*; Harnad's point is the ambient category is not given a priori for a cognitive agent — it must be grounded into existence non-symbolically. So: grounding constructs/selects the base category; once it's fixed, structural identity does real work inside it. MinSet ≈ generating set; MinSet non-uniqueness ≈ presentation non-uniqueness; Kernel/Core/Satellite ≈ a graded account of where the symbolic system depends on its cyclic base. The symmetry rider (both philosophy facet drafts stress it): a thoroughgoing structuralist who dissolves grounding in cognitive semantics owes mathematics the same story — Benacerraf's access problem is Harnad's question in mathematical clothing. The dictionary graph is only an *analogy* to a category (its edges don't supply identities/composition/functoriality) — keep that in scope. (`reports/synthesis-facet-philosophy-{codex,gemini}.md`, `reports/swanson-yoneda-harnad-findings.md`.)

**The empirical adjudication (run this round).** Psycholinguistic regression (`reports/psycholinguistic-regression-findings.md`): joining SUBTLEX-US Zipf / Kuperman AoA / Brysbaert concreteness onto the graph (all-three intersection 27,356 nodes, 53.7% inside the Kernel), the **psycholinguistic block adds ≤ 0.01 ΔR²/ΔAUC over the structural block** (degree, SCC structure, cycle participation, PageRank-likes, POS) for every layer/membership outcome; the Vincent-Lamarre "deeper layers = later-acquired" effect vanishes once you control for structure; reverse-PageRank / the FVS seed add ≤ +0.03 incremental R² over `log(out-degree)` for the three norms. This **refutes the strong claim** — there is no large independent extra-graph (sensorimotor) residue these norms detect that the bare relational structure obviously misses for these outcomes. It does **not** establish "meaning is Yoneda-complete," because of the binding **lexicographer's confound**: dictionaries are written *for learners*, so concrete/early/frequent words become definers *because* readers are expected to know them — which *creates* the structural features. "Block 2 adds nothing over block 1" is equally consistent with "meaning is relational" and "the graph was built from psycholinguistic salience, so it screens it off" — same regression signature, opposite causation. A clean test needs a causally-upstream sensorimotor norm (Lancaster sensorimotor norms) as an instrument, or a cross-dictionary comparison (Longman's controlled defining vocabulary). The **ranking-semantics follow-up** (`reports/ranking-valuation-oewn.md`) confirms the deflation from a third angle: every gradual argumentation semantics tried (h-categorizer, categoriser, burden, counting; both orientations) is an arithmetic re-skin of degree on the bare `lemma::pos` digraph — best incremental R² over `log(out-degree)` ≈ +0.023 on a ~0 baseline — and the *sign is wrong* for "foundational" under the attack reading (a heavily-used genus word like `act::n` has many attackers → low score; these rank dictionary leaves high). Methodological note: `argumentation.ranking` is for *attack* graphs; reading definition edges as attack ranks leaves as foundations — the sign-correct import is the *bipolar/support* side, which the sense-level rebuild now enables.

## 2. The argumentation-framework reframing, and the scaling result

**The reframing** (`reports/sibling-tools-connection.md`): the definition digraph *is* an instance of "what survives when support is circular and the verdict is underdetermined," which is exactly what formal argumentation / belief revision / defeasible logic formalize — and Q owns reference implementations of all three.

- A dictionary graph is a **bipolar AF / ADF**: definition edges are *support* (`u → v` = "you can't know v until you know u"); the *attack* edges are exactly what the `lemma::pos` collapse discards (polysemy, prototype exceptions); each word carries an acceptance condition over its definiens' statuses. `argumentation` has `bipolar.py` (a second `supports` relation) and `adf.py` (typed acceptance-condition ASTs).
- **MinSet = a minimal-enforcement set** (`enforce_skeptical`) — Massé's theorem as a corollary of AF enforcement — and an **FPT backdoor parameter** (Dvořák-Pichler-Woltran) for the hard semantics: deleting an FVS makes the framework acyclic, hence tractable; reasoning is fixed-parameter tractable in the FVS size. **"Many MinSets, none privileged" = stable-extension multiplicity** (a 2-cycle `A↔B` has exactly two stable extensions `{A}`, `{B}`); the math facet's read: this isn't embarrassing, it's "a family of admissible grounding choices," and ranking them requires an explicit cost function (psycholinguistic plausibility / pedagogical utility / sensorimotor accessibility / cross-dictionary stability — "smallest" ≠ "best grounded").
- **Kernel-vs-loop-ecology = grounded-vs-preferred semantics = foundationalism vs coherentism.** Grounded = the skeptical, well-founded, foundationalist reading (Harnad's pressure: some words must be learned non-verbally or the dictionary never bottoms out; Massé's FVS theorem is the formal analogue); preferred/stable = the coherentist readings (Levary's "loops are signal" — short definitional loops are semantically coherent, over-represented vs randomized controls, historically clustered; distributional/structuralist semantics agrees). Dung's theory makes the disagreement precise without settling it. (`reports/synthesis-facet-philosophy-{codex,gemini}.md` §2.)
- Dictionary editions = AGM belief revision; "how foundational is this word" = epistemic entrenchment / Spohn rank — *framework borrowed, library can't carry it* (`../belief-set` hard-caps `max_alphabet_size = 16`; build the OCF from the graph yourself, e.g. `layer index → Spohn rank`). Three unrelated "kernel"s — the meanings-repo Kernel, AGM "kernel contraction" (Hansson), `af_revision.py`'s "kernel" (Baumann) — the word collision is a coincidence, not a bridge.
- Polysemy / WSD = defeasible reasoning; a circular ungrounded definition produces `UNDECIDED`, not an error — Harnad's "recursive definability ≠ meaning" mechanized.

**The scaling result (this round).** "Argumentation can't run on a 160k-node graph" is retired in code, not just argued:
- The patched `argumentation.dung.grounded_extension` (upstream `4a1c31cc`, verified MERGE in `reports/verify-argumentation-perf-fixes.md`: 806 tests pass, 257 Dung + 120 bipolar instances bit-exact vs a reference fixpoint, 50k-node graph in 0.13 s) computes the grounded extension over the full 160,010-node OEWN attack-AF in **~1.5 s** (was >200 s and killed before the fix). The grounded extension (5,043 nodes under the attack reading) is *not* the Kernel decomposition under either edge reading — and that's the expected answer (an FVS member is grounded-from-outside; the grounded extension is what's forced from inside; overlap ≈ 2). (`reports/argumentation-bridge-oewn.md`.)
- **The Kernel AF has no stable extension** — z3 decides the whole 18,151-node Kernel attack-AF UNSAT in ~8 s and the 8,138-node giant core SCC UNSAT in ~3.3 s; of ~693 non-singleton Kernel SCCs, 630 SAT / 63 UNSAT (odd cycles). So "MinSet ↔ stable-extension outsiders" does *not* hold here; there is no stable extension to be the outsider set of. (The math facet: this is the right answer — under the pure-attack reading the OEWN definition graph admits no fully self-consistent stance, you *must* ground something.)
- The **SCC + z3 + FVS-backdoor dispatcher** (`src/meanings/argumentation_dispatch.py`, new this round): condense into SCCs, propagate forced-OUT along the condensation DAG, decide each SCC with a per-SCC oracle (brute-force ≤ 12 nodes / z3 above / an FVS-backdoor hook for the giant core), and — the practical win — **cache the oracle by SCC isomorphism class: the 9,139 Kernel SCCs collapse to 41 distinct classes, 99.6 % cache hit rate.** It re-derives the bridge's findings (whole Kernel UNSAT, structural MinSet count = 0) in ~12 s, dominated by the one z3 call on the giant core. Exposes `dispatch_stable` / `stable_exists` / `credulous_accepts` / `skeptical_accepts` / `grounded` (delegates to the now-linear upstream) / `minset_structure` (per-SCC structural count + exact DAG-DP count, without enumerating). 25 new tests. Caveats: the FVS-backdoor is wired but defers to z3 (the giant SCC's FVS is too large for `2^|FVS|`); `stable_exists` is a greedy topological sweep — definitive for the OEWN Kernel, could over-report UNSAT in pathological context-dependent cases (the exact-count path uses full DAG DP without that issue). (`reports/argumentation-dispatch-oewn.md`.)
- The **`gunray` UNDECIDED demonstrator** (`scripts/gunray_grounding_demo.py`): a toy circular definition (`a -< b`, `b -< a`, no facts) → both `UNDECIDED`; add one grounding fact → the chain resolves to `YES`; the dialectical tree rendered. Demonstrated on a real ~9-word strongly-connected slice of the OEWN Kernel (a Greek-mythology definitional loop — `andromeda`/`perseus`/`medusa`/`pegasus`/...: ground its local FVS, the 5 satellites resolve by derivation) and on the polysemy case (a gloss-type-check argument defeats the Nobelium reading of `no`). This is "recursive definability ≠ meaning" in working code, and a paper figure. (`reports/gunray-grounding-demo.md`.)

**The complementarity** (`reports/synthesis-facet-engineering.md` §1.2): `../argumentation` provides the *semantics* (Dung/bipolar/ADF/SAT/ranking) but ships no graph toolbox (no FVS, no cycle enumeration, no public SCC API); `meanings` provides the *graph toolbox* (SCCs, induced subgraphs, FVS heuristics, the spectral layer) but has no semantics solver. `src/meanings/argumentation_bridge.py` is the seam (builds `argumentation` data structures from a `meanings` `Adjacency`, reuses `meanings.graph_analysis` for all graph work); `argumentation_dispatch.py` is the scale layer the library lacks. None of the three sibling libraries is a production graph algorithm on a real vocabulary — `gunray` enumerates argument subsets, `belief-set` enumerates `2^n` worlds, `argumentation`'s enforcement is a brute-force oracle — so the production path is: `meanings` machinery for the graph skeleton + the sibling libraries (and their semantics) as *per-SCC / per-profile oracles* and as the *conceptual type system*.

## 3. The ingestion redesign — `lemma::pos` is the wrong granularity, and the fix ran

**The problem** (`reports/synthesis-facet-datamodel-{claude,gemini}.md`, `notes/upgoer-identity-clusters.md`). The current `paper-wordnet` graph is one node per `lemma::pos` with the *first* synset that has a non-empty gloss as the representative — so a WordNet ordering decision determines whether `no::n` enters as "the negation" or "the element Nobelium." This conflates three distinct things: **form** (`color` vs `colour`; `No` vs `no`, which `normalize_lemma`'s lowercasing already wrongly merges), **sense** (a dictionary reading), and **identity cluster (IC)** (the referential unit). The damage is concrete and measurable: `no::n` = Nobelium pulled into the graph; **3,413 gloss self-loops** (many artifacts — a gloss for `violin::n` saying "violin" means the *intended sense*, not literal self-definition); spelling-variant inflation; constructions flattened (`bless her heart` ≠ a word-by-word composition); indexical signal lost (`warsh` indexes region/class with nowhere to put it).

**The data model** (the twin drafts converge; Claude's is the implementation-grade version with full dataclass schemas, Gemini's the executive summary): a typed stack `Form → TokenOccurrence → Reading → Sense → IC` plus `Construction`, `Metadata`, `Provenance`, `AdmissionPolicy`, with a shared 9-tag `Lexicality` enum (`lexical_word` / `symbol_code` / `abbreviation` / `proper_name` / `taxon` / `chemical` / `technical` / `phrase` / `idiom` / `uncertain` — `uncertain` is first-class, the typed analogue of `gunray`'s `UNDECIDED`). Each arrow is a *defeasible inference carrying provenance*, not a rewrite. Relations: definition edges = `supports` between resolved **Sense** nodes (making the sense graph the honest bipolar-AF/ADF — *not* the `lemma::pos` graph); rival senses of a form `attack` each other (defeasible WSD, `gunray`-shaped, the dialectical tree = the merge/exclusion rationale the admission policy demands); IC merge = a `belief-set` profile merge over sense clusters that **keeps both forms** and carries per-merge provenance — never canonicalization. Referential content (glosses, definiens-edges, IC membership) is separated *structurally* from indexical signal (`Metadata.speaker_signal`, and arguments about the speaker) — `warsh` shares `wash`'s IC; its "indexes Appalachian/older/working-class" is metadata on the form, never allowed to fork the IC. The type system enforces the "not just an LLM" invariants by making "embeddings decide" *unrepresentable*: an `LLM_PROPOSAL`/`EMBEDDING` provenance can only attach to an argument, never directly to a lexicality/membership/edge decision. The two deliverable surfaces: the **strict typed seed** (the FVS / grounded extension restricted to typed-lexical ICs — a research artifact, "graph necessity") vs the **human Up-Goer list** (the admitted extension of a defeasible admission theory over typed IC nodes — shaped by editorial policy, "human-primitive admission") — *different objects, not subset-related; never to be conflated* ("graph necessity is not human-primitive admission").

**The rebuild ran (this round).** `src/meanings/lexicality.py` (the ingestion-time classifier), `src/meanings/identity_clusters.py` (spelling-variant merge records), `build_sense_level_paper_wordnet_graph` (sense nodes carrying lexicality tag + source synset + IC id; definition edges resolving same-surface gloss references to the intended sense), `scripts/sense_ingestion_rebuild.py`, `notes/sense-ingestion-design.md` (the type contract). Result: sense-level graph = **212,478 sense nodes / 418,094 edges; Kernel 12,142** (vs the lemma-level 18,151), Core 1,939, Satellites 10,203, seed 1,582; residual cyclic SCCs after the seed = **0** (acyclic definitional closure holds). **Zero surviving gloss self-loops** (vs 3,413 at lemma level) — the self-loop-artifact prediction *passes*: resolving same-surface gloss references to the intended sense dissolves them all. **4,562 short non-lexical artifacts** (the `no::n`=Nobelium / `s::n`=sulfur class) quarantined or excluded; **7 spelling-variant ICs over 14 forms** merged. Exports: `data/oewn-sense-strict-seed.json` (834-IC strict lexical seed) and the human Up-Goer IC vocabulary (121,375 admitted ICs + aliases + exclusions; gitignored — 35 MB, regenerable). (`reports/sense-ingestion-rebuild.md`, `reports/oewn-sense-ingestion-summary.json`.)

**The honest caveat.** The "Kernel shrank 18,151 → 12,142" comparison is *not* apples-to-apples — the node surface changed (every OEWN sense kept, vs collapsed to one `lemma::pos` node). The load-bearing claim is the *self-loop dissolution + the artifact removal + the acyclic-closure-holds*, not the raw size drop. The datamodel-Claude facet flags the one design decision the twin drafts didn't fully pin down: whether the strict-seed Kernel should be computed on the **IC-projected** graph (Claude's choice) or on the **raw sense graph with IC-restriction applied only at seed-export** — the two give different Kernel numbers, the upgoer note doesn't decide it, and the current `data/oewn-sense-strict-seed.json` reflects whatever `scripts/sense_ingestion_rebuild.py` does (verify which). The IC-merge whitelist (7 spelling-variant pairs) is currently hand-picked, not a method — a real limitation, and an obvious critic target.

## 4. Where the project over-claims, and where it's solid (the philosophy facet's verdict, adopted)

**Can defend:** a dictionary graph makes recursive definability measurable; grounding sets are feedback vertex sets; the Kernel/Core/Satellite/MinSet anatomy is stable and useful; loops are semantic structure as well as obstacles; psycholinguistic salience is largely *mirrored* in graph structure on the current OEWN artifact; `UNDECIDED` is the right formal status for circular ungrounded definitions; the sense-level rebuild dissolves the gloss-self-loop artifacts. **Should not claim:** that a MinSet is a set of ultimate semantic primitives; that recursive definability is intrinsic meaning; that degree / PageRank / ranking semantics / FVS membership gives a deep continuous measure of groundedness on the bare `lemma::pos` graph (every such score collapsed to degree, with the wrong sign under the attack reading); that the psycholinguistic regression proves meaning is relationally complete (the lexicographer's confound is fatal — the structure may mirror the norms *because* the graph is a cultural artifact made by humans for humans, not because relations alone constitute meaning); that a raw graph node is already a human word. The strongest position is modest but durable: dictionary graphs **locate the places where a symbolic lexicon cannot justify itself from within**; grounding and coherence are not enemies (grounding supplies the non-symbolic category-selection without which the system is parasitic; coherence supplies the internal relational identity once the system has something to be about).

## 7. Open / contested / load-bearing-but-unverified (the things a critic should poke)

- **The argumentation reframing might be a relabeling, not a result.** The FVS ⇔ enforcement / FPT-backdoor identification is mathematically real (the math facet states it as a theorem-level claim), and the *sense*-level bipolar/ADF encoding is net-new — but the *demonstrator* that makes "MinSet = stable extension" concrete on real data hasn't been built (#3 above), and on the bare `lemma::pos` graph the argumentation semantics collapsed to degree. Until #3 ships, "the dictionary graph is an ADF" is a true statement that hasn't yet *done* anything the FVS/Kernel machinery wasn't already doing.
- **The project might be reinventing distributional semantics with extra typed steps and worse data.** Counter-argument (the upgoer invariants): distributional semantics is "vector soup" — the target here is *typed, inspectable, falsifiable, provenance-bearing*; correlation supplies arguments, typed rules adjudicate. But the burden is on the typed system to *do better* than the soup at something — and the only empirical comparisons so far (spectral, ranking, psycholinguistic) returned "the graph mirrors degree / the norms," not "the typed structure beats the embedding." The win has to come from the sense-level data model + the argumentation semantics, and that's #3.
- **The sense-level rebuild's numbers might be cooked.** "Zero surviving gloss self-loops" is a strong claim; "4,562 short non-lexical artifacts quarantined" depends on the lexicality classifier's precision, which hasn't been independently audited; the IC-merge whitelist is 7 hand-picked pairs, not a method; the Kernel-shrinkage is across different node surfaces. A verifier pass (#7) and the IC-merge method (#6) are the answers, but they're not done.
- **Yoneda-completeness is untouched.** The regression refuted only the *strong* extra-graph-residue claim; the lexicographer's confound is the binding limit; the clean test (Lancaster sensorimotor norms as an instrument, or the cross-dictionary comparison) is #4 and not done.
- **`formal-argumentation` is pinned to a git commit (`4a1c31cc`), `z3-solver` is a hard dep, `gunray` newly added** — all experiment-tier; the upstreamed perf fix should land in a tagged release and the pins move forward; if the bridge doesn't graduate, the deps should be dropped.
- **The diachrony/entrenchment line is a framing, not a build** — `belief-set`'s `max_alphabet_size = 16` makes it useless at scale; the OCF must be built from the graph; and the LDOCE-revision data doesn't exist in the repo.
