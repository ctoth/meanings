# Sibling tools: `argumentation`, `belief-set`, `gunray` — what they're good for here

**Date:** 2026-05-12
**Inputs:** `reports/sibling-tool-argumentation.md`, `reports/sibling-tool-belief-set.md`, `reports/sibling-tool-gunray.md` (per-repo inventories), plus the Swanson-pass deliverables (`reports/swanson-synthesis.md`, `reports/spectral-valuation-oewn.md`).

## The one-sentence claim

This repo studies *what a word means when the structure that should fix its meaning is circular and the answer is underdetermined* — and answers it with graph theory only (feedback vertex sets, SCCs, leaf-stripping, a PageRank that turned out to be laundered out-degree). "What do you accept when the supporting structure is circular and the verdict is underdetermined" is exactly what formal argumentation, belief revision, and defeasible logic were built for; the dictionary graph maps onto an **abstract dialectical framework / bipolar AF** whose minimal-enforcement set *is* the MinSet, whose stable-extension multiplicity *is* the MinSet non-uniqueness, whose grounded-vs-preferred split *is* the Kernel-vs-loop-ecology split, whose revision theory *is* the diachrony story, and whose entrenchment/Spohn machinery *is* the graded foundationalness the spectral pass failed to produce. Three reference implementations of all this sit in `../`.

## What the scouts actually found (calibration)

- **`argumentation`** (`formal-argumentation`, ~20.5k lines, zero core deps): the heavyweight. Has Dung AAFs (full semantics zoo), ASPIC+, ABA/ABA+, **ADFs with typed acceptance-condition ASTs**, **bipolar AFs** (a second `supports` edge relation), value-based AFs, SETAFs, claim-augmented AFs, partial/incomplete AFs, **AF revision, dynamics, minimal-change enforcement**, probabilistic AFs, **gradual/ranking semantics** (h-categorizer, burden, Potyka, DF-QuAD, Shapley), weighted AFs, SAT/ASP/datalog encodings, ICCMA interop. Core object `ArgumentationFramework = (frozenset[str] nodes, frozenset[tuple[str,str]] edges)` — the OEWN definition digraph is a *relabeling* of this, not a restructuring. **It ships no graph-theory toolbox** (one private Tarjan SCC for cf2/stage2; no FVS, no cycle enumeration, no public SCC API). And it already has an **optional-dependency adapter for `gunray`**.
- **`belief-set`** (`formal-belief-set`, ~700 lines): finite propositional belief revision — Darwiche-Pearl revision, full-meet contraction (no partial-meet / Hansson "kernel" contraction / Levi constructor), expansion, Nayak-Spohn lexicographic + Booth-Meyer restrained revision, IC merging, `SpohnEpistemicState` (OCF over `2^n` worlds), `EpistemicEntrenchment` derived from the OCF. **Hard `max_alphabet_size = 16`** — cannot represent a real vocabulary; it *transforms* OCFs you supply, never infers one; has some documented unfixed bugs. Weakest of the three for direct use.
- **`gunray`** (zero deps, MIT): García & Simari 2004 Defeasible Logic Programming — `DefeasibleTheory` (facts + strict + defeasible rules + defeaters + presumptions + rule-id superiority), `DefeasibleEvaluator` builds dialectical trees, marks U/D by Procedure 5.1, answers **four-valued (`YES`/`NO`/`UNDECIDED`/`UNKNOWN`)** with a full "explain why" facility (`build_tree`, `explain`, `render_tree_mermaid`, `DefeasibleTrace`). Brute-force argument enumeration — built for small hand-authored theories, will not scale to a WordNet-sized rule base. (README headline snippet is stale; live keys are `yes`/`no`/`undecided`/`unknown`.)

**The size reality:** none of the three is a production graph algorithm. `argumentation`'s enforcement is a brute-force `max_cost`-bounded oracle; `gunray` enumerates argument subsets; `belief-set` enumerates `2^n` worlds. So their value here is **(a) the conceptual framing — "the dictionary problem is an instance of X, here are the relationships X gives you for free", (b) small worked examples / demonstrators that make the framing concrete and publishable, (c) the meanings repo's own FVS/SCC/spectral machinery is what would make any of it scale.** This is a *theory import* with a *demonstrator tier*, not a "swap in this library and process 160k nodes" move.

## The six connections, with verdicts

### 1. A dictionary graph is an ADF (and a bipolar AF). — `argumentation`. **Verdict: build it. Highest-value.**

A definition is *support*, not attack: "a kitten is a young cat" means you can't know `kitten` until you know `cat`. So the definition digraph is a **bipolar AF** — definition edges are `supports`; the *attack* edges are exactly what the repo currently discards by collapsing `lemma::pos`: polysemy and prototype exceptions. Sharper still, it's an **ADF**: each word carries an acceptance condition over its definiens' statuses ("you know `w` iff you know [a Boolean combo of] the words in its definition"). An ADF's well-founded model = the unique skeptical grounding; its two-valued models = the candidate complete groundings. `argumentation`'s `adf.py` and `bipolar.py` already implement this. **Nobody has written a dictionary graph down as an ADF** — the dictionary-graph people (psycholinguists, graph theorists) don't know ADFs exist, and the ADF people don't read psycholinguistics. Net-new bridge; we own the implementation.

*Glue:* build the bipolar AF / ADF from a small OEWN gloss subgraph (~100–500 words, or a toy learner-dictionary), run the library's grounded + preferred + stable semantics, and show: grounded extension = the acyclically-determined vocabulary; stable extensions = the candidate groundings; **enumerating stable extensions = enumerating MinSets**. ~100–200 lines + the existing graph-build. Small-scale (brute force), which is fine for a demonstrator.

### 2. The MinSet *is* a minimal-enforcement / revision object. — `argumentation`. **Verdict: state the theorem (free); demo with `enforcement.py` (cheap, small-scale).**

Read the definition digraph as an attack graph. Removing a feedback vertex set makes it acyclic; an acyclic AF has a *unique* extension (grounded = preferred = stable). So an FVS is "the minimal set of arguments whose status you must fix externally to make the framework's verdict determinate" — verbatim, "the minimal vocabulary you must ground from outside so every other word's meaning is determined by recursive unfolding." That is Massé's theorem *and* a special case of AF enforcement (`enforce_skeptical`/`enforce_credulous`/`enforce_extension` in `enforcement.py`). And Vincent-Lamarre's **"many MinSets, none privileged" is multiplicity of stable extensions**: a 2-cycle `A↔B` (A defined via B, B via A) is a 2-cycle attack graph with exactly two stable extensions `{A}`, `{B}` — ground A *or* B. The **grounded** extension (skeptical, always unique) ≈ the **"Rest"** — the acyclic part with no choices to make.

*Glue:* (a) half a page of prose stating "FVS of the definition digraph ⇔ minimal enforcement set forcing skeptical determinacy" — goes straight into the "Discrete Grounding and Spectral Valuation" paper; (b) on the same small subgraph as #1, run `enforce_skeptical` and confirm it returns (a) MinSet(s); ~30 lines.

### 3. Kernel vs loop-ecology = foundationalism vs coherentism = grounded vs preferred semantics. — `argumentation`. **Verdict: framing only; near-zero code.**

Harnad is a foundationalist (you need grounded base symbols). Levary ("loops are signal, not noise") and the distributional/structuralist crowd are coherentists (meaning is the whole mutually-supporting web). Dung's **grounded** semantics is the foundationalist reading (build up from the unattacked only); **preferred/stable** are the coherentist readings (maximal self-consistent stances, cycles included). The repo's two stances toward cycles — cut them (Kernel) vs inhabit them (loop ecology) — are *two argumentation semantics over the same graph*, and the library hands you the formal relationship (grounded ⊆ every complete extension; etc.). This is the Yoneda/Harnad debate from the Swanson pass given a computational home. No glue needed — it's an interpretive frame for the synthesis and any write-up.

### 4. Dictionary editions = belief revision; foundational-ness = entrenchment / Spohn rank. — `belief-set` (framework, not code). **Verdict: borrow the framework; the library can't carry it.**

Edition→edition is an AGM revision (definitions retracted = contraction, added = revision). **Epistemic entrenchment** (total preorder on beliefs; more entrenched = harder to give up) is "which words are most resistant to redefinition" = the Kernel/Core, graded. A **Spohn ranking / OCF** (integer plausibility grades over a finite space) is the natural tool for a graded "how foundational" measure — which the spectral-valuation line groped toward and missed (the layer index is *already* an integer ranking; Spohn gives the algebra). **But** `belief-set`'s `max_alphabet_size = 16` makes it useless on a real vocabulary, and it only transforms OCFs you supply. So: take the *postulates and the entrenchment ⇄ OCF correspondence* as the framing, build the OCF yourself from the graph (e.g. `layer index → Spohn rank`, or `−log(reverse-PageRank)`), and don't try to run the library at scale. (Footnote: AGM "kernel contraction" — Hansson's minimal-implying-subsets notion — is a *different* "kernel" from the meanings repo's; `belief-set` doesn't even implement it. So is `af_revision.py`'s "kernel" (Baumann's update-equivalent attack relation). Three unrelated "kernel"s; the word collision is a coincidence, not a hidden bridge.)

### 5. Polysemy / word-sense disambiguation = defeasible reasoning. — `gunray` (and ASPIC+ in `argumentation`). **Verdict: demonstrator-tier; the cleanest illustration of the thesis.**

WordNet gives a lemma multiple synsets; in context one reading wins. That's defeasible: `sense_i` and `sense_j` attack each other, context supplies arguments, the accepted extension is the disambiguated reading — and `gunray`'s dialectical-tree explainer shows *why* one reading defeats another. Crucially: a circular ungrounded definition (`r1: a -< b; r2: b -< a`, no facts) produces **`UNDECIDED`** — not an error, not an arbitrary pick — and adding a grounding fact flips the dependents to `YES`. That is a *working formal analogue of the whole grounding thesis in ~20 lines*: the Kernel is the `UNDECIDED` circular core; choose a minimal grounding set; the Satellites become derivable. It's also a clean argument that recursive definability ≠ meaning, in code (Harnad's point, mechanized).

*Glue:* a ~20–30-line `gunray` script: a tiny circular definition theory → `UNDECIDED`; add one grounding fact → the chain resolves to `YES`; render the dialectical tree. A figure for the paper, and a unit-test-sized demo. (Scaling to real WordNet polysemy is *not* cheap — `gunray` is brute-force; this stays a demonstrator.)

### 6. Gradual / ranking-based semantics = the spectral valuation, done right. — `argumentation`. **Verdict: do it; a real, non-degenerate replacement for the PageRank attempt.**

The spectral pass concluded reverse-PageRank ≈ out-degree, adds essentially nothing over degree. `argumentation`'s `ranking.py` has h-categorizer, burden-based, Potyka, DF-QuAD, Shapley — semantics *designed* to rank arguments by defensibility accounting for attack/support topology, not degree count. Run one (or several) over the definition graph-as-bipolar-AF and you get a principled "how grounded is this word" score to put against the FVS, the layers, and the psycholinguistic norms — the non-degenerate replacement for the PageRank line. ~50–100 lines (build bipolar AF, call `ranking.py`, join with the existing `reports/spectral-valuation-oewn.json` comparison harness). Caveat: some of these semantics may also be O(graph) and degree-dominated on a sparse graph — the comparison itself is the experiment, and "another principled score that *also* collapses to degree" is a publishable negative result too.

## What to do next, ranked

1. **Build the bipolar-AF / ADF encoding of a small dictionary subgraph and run grounded + stable semantics** (#1, #2 demo) — the headline artifact: shows MinSet = stable extension, FVS = enforcement set, Rest = grounded extension, all on real (small) data, using a library we own. New module `meanings.argumentation_bridge`, script + report.
2. **Write the FVS ⇔ enforcement theorem** (#2 prose) — half a page into the "Discrete Grounding and Spectral Valuation" paper outline; reframes Massé's result as a corollary of AF enforcement.
3. **Ranking-based-semantics valuation** (#6) — run `argumentation/ranking.py` over the bipolar definition AF, compare to FVS/layers/norms; either a better foundationalness score than PageRank, or a publishable "also collapses to degree."
4. **`gunray` UNDECIDED demonstrator** (#5) — ~20-line script + a dialectical-tree figure; the mechanized version of "recursive definability ≠ meaning."
5. **Frame the synthesis around grounded-vs-preferred** (#3) — interpretive, no code; folds into `swanson-synthesis.md` and any paper.
6. **Borrow the entrenchment/OCF framing for the diachrony line** (#4) — when/if the cross-dictionary-editions data appears; build the OCF from the graph, cite AGM, don't run `belief-set` at scale.

The unifying upgrade: stop treating the definition graph as *only* a graph. It is an argumentation framework; the repo already computes the graph-theoretic skeleton (SCCs, FVS, layers, spectral scores) that the argumentation library *lacks* — so the two are complementary, and putting them together turns "here is a feedback vertex set" into "here is the minimal enforcement that makes meaning skeptically determinate, here are all the alternatives, here is what each one costs, and here is the semantics under which loops are kept rather than cut."
